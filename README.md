# Data Structures: Stack Implementation in C

A core Data Structures & Algorithms (DSA) C application demonstrating the **LIFO (Last In, First Out)** stack data structure implemented via linked list pointers.

## Concepts Covered
* **LIFO Principle**: Managing data insertions and deletions exclusively at the top pointer.
* **Stack Operations**: Implementing `push`, `pop`, `peek`, and `isEmpty` algorithms.
* **Dynamic Memory**: Preventing stack overflow and handling heap allocation safely.

## How to Compile & Run
```bash
gcc main.c -o stack_ds
./stack_ds
